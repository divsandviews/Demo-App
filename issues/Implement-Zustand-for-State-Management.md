### Task Request

#### Description
Transition the state management of the entire demo app to use Zustand. Zustand is a small, fast, and scalable state-management library for React.

#### Requirements
- Replace the existing state management implementation (if any) with Zustand across the entire app.
- Ensure modularity and scalability for future additions to state management.

#### Deliverables
- Documentation explaining how Zustand has been implemented and instructions for other contributors.
- Relevant unit tests or integration tests to validate Zustand integration.
